# Background music

Place royalty-free, redistributable MP3 files here when you want optional background tracks:

| Option key          | Filename           |
| ------------------- | ------------------ |
| `peaceful_piano`    | `peaceful_piano.mp3` |
| `ambient_pad`       | `ambient_pad.mp3`    |
| `soft_strings`      | `soft_strings.mp3`   |
| `gentle_choir`      | `gentle_choir.mp3`   |

If a selected file is missing, SacredClips skips music for that render and continues without error.
